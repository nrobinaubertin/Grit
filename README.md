# Grit, modified version

This is a modified version of [Grit](https://github.com/shub39/Grit) by shub39, for my own needs. It is not an official Grit release.

The changes in this fork are completely vibe coded: an AI coding assistant wrote them from my instructions. Treat them as such. Expect bugs, and keep backups of your data.

## Main changes from Grit

- A Calendar tab that syncs with a CalDAV server, for example Radicale. Two people can share calendars without another sync app such as DAVx5. The tab has month, week and agenda views, categories with colors, reminders, and calendars that stay on the device only. On Android, it can also show the calendars of other apps on the phone, read-only. See [shared/calendar/README.md](shared/calendar/README.md) and the server setup in [server/radicale/README.md](server/radicale/README.md).
